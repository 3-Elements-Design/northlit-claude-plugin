Build a 3D model with Northlit's scene builder:

$ARGUMENTS

Read `get_skill` with name `scene-builder-3d` first — it carries the module contract and the loop.

1. Start the scene with `create_scene`: an empty stage, a module you wrote, or `fromGlbUrl` for a model that exists (a `generate_3d` result, an upload). Pass `runId` to put it on an existing canvas; omit it for a canvas of its own. It answers with a contact sheet (hero / front / right / top) — look at it.
2. Build it up with `edit_scene`: resubmit the WHOLE module with one change per call and a `note`; pass the `revision` you last saw and a fresh `opId`. Each edit renders a new sheet — proportions first, detail last. A module that throws comes back as an error with the message: fix and resubmit, nothing was committed. Textures or models the module needs go in through `import_scene_asset` first.
3. Organic realism (a car body, a character, food)? Make a concept image with `generate_image`, turn it into a mesh with `generate_3d`, and bring that GLB in with `fromGlbUrl` — then stage and light it in the scene.
4. When it is right: `render_scene` with `quality: "final"` for the views you want (or a `camera`) and a `turntable` — stills land as cards under the scene, the clip as its video. `export_scene` for the GLB (a 3D model card that opens in the viewer; usable in prototypes).
5. A finished photograph of a view: `generate_scene_angles` — the render fixes camera, framing and light; your prompt supplies materials and setting; `product` or `referenceImageUrl` carries identity. One image credit.
6. `read_scene` shows the current module, graph and revisions; `revert_scene` makes an earlier revision the head again.

A successful run is not a correct render: say what the latest sheet shows before calling the scene done. For a flat picture of something 3D-looking, /northlit:image is cheaper; this command is for a model you can turn, re-light and export.
